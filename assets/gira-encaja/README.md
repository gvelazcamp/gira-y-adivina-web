# Girá y encajá

Prototipo pedido por Gonzalo el 05/11/2026, integrado en Extensiones con `soloGonzalo: true` e insignia Prueba. No se agregó al menú Más / Pruebas ni se habilitó para Vale u otros perfiles.

Fondo de laboratorio ilustrado generado para la prueba. Cuatro aberturas simples en una base, sin puertas dibujadas. Categorías iniciales: Animales, Plantas, Espacio y Comidas. Se elige jugar con imágenes o palabras en español. Caen tres fichas cercanas y de categorías mezcladas desde el primer nivel. Arrastrar una ficha la mueve horizontalmente; tocarla la selecciona y gira sin afectar a las otras. El botón ⇄ y la tecla C cambian la selección para usar los demás controles. También hay botones y controles de teclado (flechas, espacio para girar, abajo para soltar, P/Escape para pausa).

Cinco niveles de nueve fichas (tres tandas de tres), tres vidas propias. Caída un 25 % más rápida que la primera prueba (mínimo 30 unidades/s, antes 25). La velocidad aumenta por nivel y las aberturas alternan orientación al cambiar de nivel; desde el tercero también giran después de la segunda tanda. Los cambios de aberturas esperan a que se resuelvan las tres fichas de la tanda, para no cambiar el destino de otra ficha en pleno vuelo. El récord se guarda únicamente en `gya_gira_encaja_record_v1`. No consume fichas, vidas o monedas del juego principal. El cierre cancela animación, observador y eventos.

Validación: `BROWSER_EXECUTABLE=/usr/bin/chromium node tests/gira-encaja.cjs`. Comprueba tres fichas visibles, categorías mezcladas, giro y arrastre individuales por coordenadas reales del canvas, velocidad de caída, pausa de las tres, cinco niveles con controles reales, derrota, récord, reapertura, cuatro tamaños de pantalla y ocultamiento/bloqueo de apertura para Vale y Ana. `UI_SCREENSHOTS` permite guardar capturas.
