# Girá y Adiviná para Apple TV

Proyecto independiente de la app de Play Store. Su código para tvOS está en [`tvos/`](tvos/README.md). El Apple TV actúa como anfitrión de la Sala TV y los celulares entran por el mismo código desde la app Android o `girayadivina.com/tele`.

**Estado actual:** fuente de una primera prueba con 100 Rioplatenses, Ahorcado y El Rosco, código de sala, navegación con mando y conexión MQTT. El build de GitHub Actions compila y genera un IPA sin firma. Aún faltan los otros juegos de Sala TV, firma e instalación/prueba en un Apple TV físico. No se ha generado un IPA instalable.
