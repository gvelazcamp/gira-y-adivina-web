# Presentación y locución de extensiones

Assets gráficos del conductor oficial **Giro** para las presentaciones de los juegos de televisión.

- `Giro/`: poses del personaje y cuerpo completo.
- `Giro/bocas/`: fotogramas de expresiones de boca para futura animación.
- `Giro/elementos/`: atril y pantalla.
- `Giro/estudios/`: escenarios de televisión de 16:9.
- `Giro/escenas/`: planos de apertura y escenas de cierre.
- `Giro/efectos/`: elementos gráficos superponibles.
